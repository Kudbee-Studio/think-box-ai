# KUDBEE / Think Box — Mission

Date: 2026-08-31

## One sentence

Turn a human intent into a verified outcome by running a narrow Box on a replaceable machine, then keep the proof.

## What we are

A control plane for **Think Jobs**.

- A **Think Job** is the unit of work: intent → plan → execution → artifacts → verdict (`succeeded` | `failed` | `unproven` | `blocked`).
- A **Think Box** is one hat + tools + memory + policy. It is not a cloud brand.
- An **ExecutionProvider** is where the Box runs (Upstash, laptop, UpCloud GPU). Providers are replaceable.
- A **Hat** is a role (`researcher` first). Models are interchangeable behind the hat.

We are not a token launch, a 4K film studio, or a new indexer.

## What we are not doing this phase

- $THINK / tokenomics
- New GPUs, new Upstash boxes, deleting `…e57`
- Groq keys in git, Inception API from AWS
- Polar browser, movie swarm, Jury economy
- Claiming the DOGI indexer-split is proven when public APIs cannot see both deploys

## North-star loop

```
intent → hat → box on a provider → tools → artifacts → verdict → next job may read that proof
```

If a step needs a GPU start, a new server, or a secret in git, it is out of policy unless the human said so in the Job.

## First product

Researcher Hat: inscription / DRC-20 / wallet provenance report.

Edge: marketplace metadata is not the chain. Proof file is the product. Paid reports later. Credits / THINK only after strangers pay for a report.
