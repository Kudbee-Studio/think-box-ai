## Key Discoveries

### 1. Model Specialization
- **GPT-OSS-120B:** Best for reasoning, architecture, complex analysis
- **GPT-OSS-20B:** Best for speed, storyboards, simple tasks
- **Rule of thumb:** Use 120B for planning, 20B for execution

### 2. Production Pipeline
- Bottleneck: Text overlay rendering (requires fonts)
- Solution: Pre-render text as images, composite in parallel
- Audio mixing: 0.25 music volume is optimal

### 3. Media Pack Architecture
- Manifest format: JSON-YAML hybrid
- VRAM budgeting: Per-model allocation with hot-swap
- Version control: Semantic versioning + checksums

### 4. Token Economics
- Tokens should decay over time (knowledge freshness)
- Challenge results modify token score
- Provenance chain prevents fraud

### 5. Jury Protocol
- Randomized Knowledge Prompts (RKP) for fair evaluation
- Evidence Request Cycle (ERC) for verification
- Cross-Examination Module (CXM) for disputes
