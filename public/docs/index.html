Quick Start

Get up and running in 5 minutes

1. Install Think Box CLI

pip install think-box-ai
thinkbox init
thinkbox doctor

2. Create Your Wallet

thinkbox wallet create --name savannah
# Save your mnemonic phrase securely!

3. Connect to Solana

thinkbox config set network devnet
thinkbox wallet balance

4. Launch Your First Token

thinkbox token create --name "Savannah" --symbol SAV --supply 1000000000
