Wallet Drain Attack Vectors

Understanding how attackers drain wallets so you can protect yourself

⚠️ Important Disclaimer

This page demonstrates common wallet draining attack vectors for educational purposes only. The code patterns shown are for understanding how attacks work so you can protect yourself. Never use this knowledge to harm others.

How the Attack Works

Step 1: Lure — Attacker creates a fake NFT mint, airdrop, or marketplace that looks legitimate.
Step 2: Connect — User connects their wallet (e.g., Woof Wallet, MetaMask).
Step 3: Sign — User signs a transaction that approves the attacker to spend their tokens.
Step 4: Drain — Attacker calls transferFrom() to sweep all approved tokens.

Malicious Code Pattern

This is what a wallet drainer looks like in JavaScript:

// MALICIOUS: Fake NFT mint site
async function mint() {
  // Step 1: Get user's wallet
  const accounts = await window.doge.requestAccounts();
  const userWallet = accounts[0];

  // Step 2: Create approval transaction
  // This looks like a mint but actually approves the attacker
  const maliciousTx = {
    from: userWallet,
    to: TOKEN_CONTRACT,
    data: encodeApprove(ATTACKER_ADDRESS, MAX_UINT256) // Unlimited approval!
  };

  // Step 3: User thinks they're minting, but they're approving
  await window.doge.sendTransaction(maliciousTx);

  // Step 4: Attacker drains wallet
  await drainWallet(userWallet, ATTACKER_ADDRESS);
}

How to Protect Yourself

Check Approvals

Regularly review and revoke token approvals you've granted. Use tools like revoke.cash.

Verify Contracts

Always verify the contract address before signing. Scammers clone popular sites.

Use Hardware Wallets

Hardware wallets show exactly what you're signing on the device screen.

Never Share Seeds

Never enter your seed phrase anywhere. No legitimate site will ask for it.

Interactive Demonstration

Enter a wallet address to see how an attacker would view it. This does NOT connect to any wallet or perform transactions.
