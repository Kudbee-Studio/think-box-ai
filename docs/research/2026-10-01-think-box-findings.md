## Correction recorded

An earlier review note said token `tt_e52e627d85a9d763` "wrongly claims `fetch_url`" because run ab5e5299 "used `write_file`". **That was wrong.** The run record (`apps/web/data/runs.json`, a local git-ignored runtime file, so reproduce it from your own database; run id `ab5e5299-854f-472d-80be-0d55ed2e5184`, goal "train a think token", model mercury-2, status completed) shows these tool steps in order: `list_files`, `recall`, `fetch_url`, `fetch_url`, `write_file`, all successful. The token's tool sequence (`list_files → recall → fetch_url → write_file`) agrees with it. The defect is that the lesson is a **template-style** sentence with no reusable insight, not that it cites a tool the run never called. A "never cite a tool the run did not call" test is still worth having, but it is a guard, not a description of this bug.
